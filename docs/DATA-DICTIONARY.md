# 数据定义

元素质量按物料净重×含量汇总；干湿基转换，低于检出限给上下界，不可把未检出当零，配方版本锁定。

输入字段：lot, batch, mass, unit, moisture, element, assay, basis, revision, price。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

`price` 为可选列，单位元/kg，指该整批料的单价。缺列、空值或格式无效的料批仍参与成分计算，但不进入领料方案（列在“不可整批领用”里并给出原因），不得拿猜的价格凑方案。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

Cu和Zn目标区间为V1教学配方，不外推为生产工艺。缺测元素贡献范围按0–100%计；湿基换干基先除以干物质比例；样例存在只测单元素的料批，因此验收可能待补测。

混配按batch炉次独立计算；同一lot可在不同炉次出现，采信键为(batch,lot,element)，移除批次的试算也仅影响所属炉次。

领料方案按“整批发料、不拆包”求组合：订单量按领料称重（湿重）比较，元素含量按干基汇总；只枚举达到订单即停的整批组合。给出最低成本、成本/剩料折中、最少超量三个可执行方案，并附成本–剩料曲线。确认后的记录按订单（ORDER-<订单kg>）唯一保存，方案重算后再次确认只更新同一条并递增版本，不新增第二条。晚到化验记录会改变方案时，原确认标记为须重确认；验收按已确认的各批领料用量重算，数量锁定确认值、成分取当前批次数据。目标区间沿用 V1 教学配方 Cu 7.5–12.5%、Zn 3–7%，不外推为生产工艺。
